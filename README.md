# 岁华映彩 · 新春祈愿树

一个纯前端、零外部资源依赖的沉浸式 3D 新春圣诞祈愿树与电影级烟花贺岁交互场景，基于 **Three.js + React + TypeScript + Tailwind CSS** 构建，可直接部署至 **GitHub Pages** 在线访问与分享。

## 核心亮点

- **华丽立体圣诞祈愿树**：460+ 簇带薄雪霜色的立体松针枝桠、1680 点零闪烁暖金柔光星灯、香槟金珠链与朱红丝绒花环、180 颗红金烤漆与镜面圣诞球、红绸“福/春/吉/喜”宫灯、飘动祈愿红绸、树下红金新年礼盒与 360° 立体鎏金八芒星冠。
- **盛唐新春古城与万家灯火**：雨雪微湿青石板实时水洼倒影、四座带“恭贺新禧”匾额与春联的朱红歇山飞檐牌楼、张灯结彩灯笼长串、依山层叠的古建飞檐灯火、山谷暮霭夜雾与漫天升空的孔明灯。
- **60 秒四幕电影级运镜与烟花秀**：
  1. **第一幕 · 岁启微光（00:00 - 00:14）**：灯火沿树身自下而上渐次点亮，点亮星冠。
  2. **第二幕 · 流金映雪（00:14 - 00:28）**：大范围环绕摇臂镜头，尽览牌楼、倒影与古城万家灯火。
  3. **第三幕 · 烟火盛放（00:28 - 00:48）**：金菊、垂柳、牡丹、双环四类带硝烟微光的 3D 烟花齐放高潮。
  4. **第四幕 · 锦绣定格（00:48 - 01:00）**：黄金构图定格，缓缓浮现专属贺岁祝福与署名。
- **实时交互与纯合成音效**：
  - 点击夜空任意位置即可向目标点发射 3D 礼花；
  - 鼠标拖拽 / 滚轮随时接管自由视角；
  - 内置 Web Audio API 实时合成五声音阶古筝氛围配乐与烟花升空/绽放音效（免加载音频文件）。
- **专属贺卡定制与链接分享**：支持自定义收件人、贺岁主标题、诗意副文与署名，一键生成带参数的专属祝福链接发给亲友。

## 快捷键

| 按键 | 功能 |
| --- | --- |
| `Space` | 播放 / 暂停 60 秒演出 |
| `F` | 立即燃放一组贺岁烟花 |
| `H` | 切换纯净录屏模式（隐藏控制栏） |

## 链接参数定制祝福

部署上线后，可直接在网址后拼接参数定制祝福卡片（也可通过页面内「定制祝福」弹窗一键生成）：

```text
https://<你的用户名>.github.io/<你的仓库名>/?to=挚友与家人&h=岁岁常欢愉，年年皆胜意&s=愿这一夜流光与烟火，伴你奔赴明朗新岁&from=新春贺启
```

## GitHub Pages 一键发布（直接访问）

仓库已内置自动构建与发布工作流（`.github/workflows/deploy.yml`）及相对路径打包配置，只需两步即可开启在线访问：

1. 将代码推送到你的 GitHub 仓库（`main` 或 `master` 分支）。
2. 打开仓库页面，进入 **Settings → Pages → Build and deployment → Source**，将发布源切换为 **GitHub Actions**。

随后 GitHub Actions 会自动执行打包与部署（约 1 分钟完成），完成后即可在 **Settings → Pages** 顶部看到可直接访问的公网地址：

```text
https://<你的用户名>.github.io/<你的仓库名>/
```

## 本地开发与构建

需要 Node.js 18+ 环境：

```bash
# 安装依赖
npm install

# 启动本地开发服务器（默认端口 3000）
npm run dev

# 类型检查
npm run lint

# 构建生产静态文件（输出至 dist/）
npm run build
```

## 技术栈

- **3D 渲染引擎**：Three.js（自定义 PBR 程序化纹理、实时平面倒影 `Reflector`、夜空 IBL 环境光照、`UnrealBloomPass` 柔光泛晕、黑体冷却烟花粒子系统）
- **前端框架**：React 19 + TypeScript + Vite
- **界面样式**：Tailwind CSS v4 + Lucide Icons
- **音频引擎**：Web Audio API 纯程序化实时合成
